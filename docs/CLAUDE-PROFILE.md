## Key Workflow Components for Successful Execution

### 1. Clear Context at Session Start
Reading `CLAUDE.md` before every session eliminates re-explaining. Full context
means faster execution and fewer mistakes.

### 2. Task Tracking
Every multi-step job gets a task list. Tasks marked in-progress before starting,
completed when done. Nothing falls through the cracks.

### 3. Direct Tool Access
Shopify MCP connected = I can create products, collections, and run analytics
without the user touching the admin. GitHub + Shopify CLI connected = I can
push code directly to the live store.

### 4. Proactive Problem Solving
When a tool fails, a section type doesn't exist, or a push throws an error —
I diagnose and fix immediately rather than stopping to ask permission.

### 5. Version Control Discipline
Every change committed to master before closing a session. Staging used for
review before merging to production. Nothing goes live untested.

### 6. Specificity Over Speed
Better to ask one clarifying question upfront than to build the wrong thing.
But once direction is clear — move fast and don't wait.
